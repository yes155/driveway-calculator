## Editorial stages and locks for this bounded UI change

Step 0 brief: homepage owns tool discovery and a rectangular area check; calculators own quantities or installed cost; guides retain their answers and mapped next tasks. Evidence: free tools are specified in the original instruction set; the calculator application has no tool account/payment flow; formulas, source records and bylines already exist. No external material figure or cost has changed.

Stage 1: write access attributes, task labels, handoff instruction and footer navigation around those facts. Stage 2 locks: Free to use; No login required; Formulas & sources; length/width in feet; area in square feet; existing destination URLs; explicit scope distinction between area, material quantities and installed cost. Stage 3: simplify only supporting UI copy; leave article first answers, prices/defaults, dates, source claims and formulas unchanged. Stage 4: verify source/build/export, interaction and viewport evidence. This is a shared UI implementation review, not a completed editorial audit or approval of all 51 article drafts. The existing framework reassessment's unresolved semantic, bridge and human-review rows remain open.
